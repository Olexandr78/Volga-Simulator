# Volga Simulator — ГАЗ-24-10

Браузерный 3D-симулятор ГАЗ-24-10 на Three.js. Кузов окрашен в цвет **«слоновая кость»**.

## Запуск без Node.js

**Node.js, npm, Vite и сборка не нужны.** Проект работает как обычный статический сайт: браузер загружает Three.js с CDN.

### Вариант 1 — открыть через статический хостинг

Размести содержимое репозитория на любом статическом хостинге (например, GitHub Pages, если он доступен для настроек этого репозитория). Главный файл сайта — `index.html`. Никакой серверной части или сборки нет.

### Вариант 2 — локально на Windows

Если у тебя уже установлен Python, открой папку проекта в терминале и выполни:

```powershell
py -m http.server 8000
```

Затем открой в браузере `http://localhost:8000`.

Это встроенный HTTP-сервер Python, не Node.js. Если Python не установлен, используй любой статический HTTP-сервер или статический хостинг. Простое открытие `index.html` двойным щелчком может блокироваться браузером из-за ограничений безопасности ES-модулей.

## Управление

- **W / ↑** — газ
- **S / ↓** — тормоз
- **A / ←**, **D / →** — руль
- **Space** — ручной тормоз
- **C** — переключение камер: сзади, капот, салон, сверху
- **R** — вернуть автомобиль на старт
- **E** — запустить / заглушить двигатель
- На телефоне — экранные кнопки.

## Реализовано

- Процедурная модель кузова ГАЗ-24-10 цвета слоновой кости.
- Хром, решётка радиатора, круглые фары, фонари, зеркала, молдинги.
- Салон: сиденья, приборная панель, руль и рычаг КПП.
- Колёса с дисками, крепежом и протектором.
- Освещение, тени, тестовая дорога и окружение.
- Упрощённая модель движения, двигателя и передач.
- Четыре камеры, HUD, экранные органы управления.
- Процедурный звук двигателя через Web Audio API.

## Техническая информация

Three.js подключается напрямую через import map с jsDelivr CDN. Для первого запуска нужен интернет. После загрузки модулей браузер может кешировать их, но гарантированный офлайн-режим пока не реализован.

Модель — детализированное игровое приближение, а не CAD-копия или скан настоящей машины. Физика подвески и столкновений пока упрощена.
