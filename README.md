# Volga Simulator — ГАЗ-24-10

Браузерный 3D-симулятор ГАЗ-24-10 на Three.js. Основной автомобиль окрашен в цвет **«слоновая кость»** — тёплый светлый заводской оттенок.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

\`\`\`bash
npm install
npm run dev
\`\`\`

Открой локальный адрес Vite, обычно http://localhost:5173.

Для production-сборки: \`npm run build\`, для локального просмотра сборки: \`npm run preview\`.

## Управление

- **W / ↑** — газ
- **S / ↓** — тормоз
- **A / ←**, **D / →** — руль
- **Space** — ручной тормоз
- **C** — переключение камер (вид сзади, капот, салон, сверху)
- **R** — вернуть автомобиль на старт
- **E** — запустить / заглушить двигатель
- На телефоне доступны экранные кнопки газа, тормоза и поворота.

## Что реализовано

- Детализированная процедурная модель кузова ГАЗ-24-10: капот, багажник, крыша, стойки, окна, двери, молдинги и бамперы.
- Цвет кузова — слоновая кость; хромированные элементы, решётка радиатора, круглые фары, задние фонари и зеркала.
- Салон с сиденьями, приборной панелью, рулём и рычагом КПП.
- Колёса с боковинами, дисками, крепежом и протектором.
- Освещение, тени, тестовая дорога и окружение.
- Базовая модель движения: разгон, торможение, руление, ручник, инерция и условная работа двигателя с передачами.
- Четыре камеры, HUD со скоростью, передачей и оборотами.
- Процедурный звук двигателя через Web Audio API (включается после первого нажатия/касания).

## Технические ограничения текущей версии

Модель собрана процедурно из геометрии Three.js и является детализированным игровым приближением, а не CAD-копией или сканом настоящей машины. Динамика двигателя и трансмиссии пока упрощённая; полноценная физика столкновений, независимая подвеска, настоящие звуковые записи и точные заводские размеры требуют отдельных этапов разработки.
